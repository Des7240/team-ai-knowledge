Đồng Bộ Ngữ Cảnh AI Cho Toàn Đội Ngũ

Giải pháp lưu trữ tập trung, tìm kiếm thông minh qua chuẩn MCP. Giúp các AI Agent tự động đọc hiểu dự án và ghi nhận phiên làm việc mà không cần bạn phải thao tác tay.

🛠️ Hướng Dẫn Cài Đặt Khởi Chạy

Hệ thống hiện tại hỗ trợ Dual-Mode: chạy Local bằng tiến trình Stdio, hoặc chạy Remote bằng giao thức HTTP.

1

Chế độ Local (Stdio)

Thích hợp khi phát triển trực tiếp trên máy. Server đọc/ghi file từ ổ cứng nhanh chóng.

{
  "mcpServers": {
    "team-kb": {
      "command": "node",
      "args": ["/path/to/dist/index.js"]
    }
  }
}
2

Chế độ Remote (HTTP)

Dành cho Cloud Deployment (Render). Kết nối qua giao thức Streamable HTTP.

{
  "mcpServers": {
    "team-kb": {
      "type": "streamable-http",
      "serverURL": "https://team-kb-mcp.onrender.com/mcp"
    }
  }
}
3

Cấu hình Biến Môi Trường (Remote)

Nếu bạn triển khai lên Render, hệ thống cần quyền ghi vào repo GitHub của team.

GITHUB_TOKEN=github_pat_...
GITHUB_OWNER=username
GITHUB_REPO=repo-name
4

Tự Động Chuyển Đổi Mode

Server rất thông minh! Nếu nhận diện thấy có GITHUB_TOKEN, nó tự động mở cổng HTTP. Ngược lại, nó sẽ khởi động ở Local mode.

🔄 Quy Trình Làm Việc Hàng Ngày

Dev không cần phải thay đổi thói quen code, AI Agent sẽ tự động làm phần việc nặng nhọc.

Khi bắt đầu phiên (Bắt đầu code):

AI Agent sẽ tự động nạp AGENTS.md và tự động gọi tool get_overview để đọc cấu trúc dự án. Bạn chỉ cần ra lệnh: "Tôi muốn làm tính năng A cho project B".

Khi gặp lỗi khó hoặc cần tìm best practice:

Bạn ra lệnh: "Tìm xem team mình có quy chuẩn nào về xử lý lỗi không?". AI sẽ gọi tool search_knowledge tìm kiếm tự động toàn bộ Markdown và trả về kết quả ngay lập tức.

Khi kết thúc phiên (Commit code):

Bạn ra lệnh: "Tổng kết phiên làm việc". AI sẽ tự động phân tích các file vừa sửa và gọi tool save_session để sinh ra 1 file Markdown chuẩn hóa lưu vào thư mục dự án.

💡 Giải Pháp & Kiến Trúc Xử Lý Cốt Lõi

Hệ thống này sinh ra để giải quyết các hạn chế kỹ thuật lớn nhất khi chia sẻ ngữ cảnh AI.

1. Giải quyết bài toán lưu trữ phân tán (Ephemeral File Systems)

Khi đưa server lên nền tảng đám mây miễn phí như Render, đĩa cứng sẽ bị xoá ngay sau khi khởi động lại. Hệ thống giải quyết bằng DataProvider Abstraction, tự động phát hiện môi trường và uỷ thác mọi thao tác Đọc/Ghi dữ liệu (như Save Session) trực tiếp qua GitHub Contents API thay vì ghi vào ổ cứng tĩnh. AI của mọi người trong nhóm sẽ luôn có data mới nhất theo thời gian thực.

2. Khắc phục giới hạn Rate Limit của GitHub API

Việc tool Search phải gọi API tới toàn bộ tài liệu Markdown sẽ gây tràn Rate Limit ngay lập tức. Khắc phục bằng cơ chế In-Memory Caching & Warm-up. Server sẽ tải toàn bộ cấu trúc file về bộ nhớ Ram một lần duy nhất với TTL 5 phút, đảm bảo tốc độ phản hồi tính bằng millisecond (ms) không độ trễ!

3. Khắc phục lỗi chuẩn hoá tên miền, font chữ Tiếng Việt

Việc AI sinh file với tên tiếng Việt chứa dấu sẽ gây lỗi hiển thị trên nhiều hệ điều hành và link truy cập. Hệ thống tự động xử lý thông qua helper toSlug() - bóc tách dấu câu tiếng Việt an toàn về tiếng Anh (a-z) chuẩn SEO và gạch ngang nối từ.

🔌 Danh Sách 10 MCP Tools Active

Hệ thống cung cấp sẵn các công cụ giao tiếp cho AI Agent chạy ổn định trên cả stdio lẫn HTTP.

  • auto_context — Bộ xử lý luồng thông minh (Orchestrator). Tự động quyết định và gọi các Tool thích hợp bên dưới để cung cấp thông tin cho AI (Zero-config).
  • get_overview — Lấy cái nhìn tổng quan về thư mục toàn bộ Knowledge Base.
  • get_project_context — Nạp context riêng lẻ cho 1 dự án cụ thể.
  • search_knowledge — Tìm kiếm linh hoạt Full-text Search vào chỉ mục hoặc qua Cache.
  • get_pattern / get_decision / get_lesson — Bộ 3 công cụ truy xuất tài liệu chuyên biệt (Patterns, ADRs, Lessons).
  • save_session / save_lesson — Ghi trực tiếp tài liệu từ AI. (Hỗ trợ commit qua Github API ở mode HTTP).
